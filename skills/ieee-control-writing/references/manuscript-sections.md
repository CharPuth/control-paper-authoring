# Sentence frames by manuscript function

M04 provides wording. The active field profile's M01 determines chapter order and content. In the default control profile, the introduction progresses through practical significance, prior work, the research problem, and the method with validation. This line identifies the frame groups below; detailed structural rules are maintained only in M01.

## Abstract

- "During [operation], changes in [physical quantities] affect [controlled behavior]."
- "We develop [controller] that adjusts [commands] to compensate for [specified effects]."
- "The controller retains [existing components]."
- "Across [tested conditions], the method reduces [metric] by [reported amount]."

## Introduction

| Function | Optional frame |
| --- | --- |
| Actual task and value | "[Application task] requires [documented capability] under [conditions]." |
| Platform capability | "[Platform class] supports [application] through [capability]." |
| Prior achievement | "[Authors] developed [platform or method] for [task]." |
| Prior control approach | "For [control task], [authors] proposed [method] to address [effect]." |
| Established foundation | "These studies establish [supported capability] under [reported conditions]." |
| Remaining issue | "Under [target condition], [supported unresolved issue] remains." |
| Present question | "The resulting problem is to [objective] while [design requirement]." |
| Proposed approach | "To address [problem], we develop [method] that [key action]." |
| Validation | "We evaluate [property] in [simulation] and examine [capability] in [experiments]." |

Use only the supported functions and actual validation types. These are original examples, not quotations or a mandatory sentence count.

## Contributions and transitions

- "We formulate [problem] at the [interface], which allows [supported consequence]."
- "We develop [method] to compensate for [effects] as [conditions] change."
- "We evaluate [method] over [conditions] without retuning [specified settings]."
- "Using the model in Section [identifier], we design [controller]."
- "The resulting [command] is passed to [next component]."

Use a transition to explain dependency or sequence, not to repeat the heading.

## Interpretation and conditions

- "The reduction in [metric] is consistent with [established mechanism]."
- "The results indicate [supported behavior] over [tested range]."
- "The improvement is largest in [condition], where [observation]."
- "The model assumes [necessary condition]."
- "[Reported result] holds under [stated conditions]."

## Conclusion

- "We developed [method] for [specific task]."
- "The controller adjusts [commands] to account for [supported effects]."
- "The experiments showed [specific result] across [tested conditions]."
- "Future work will address [author-approved task]."

Select actual contributions and supported findings. Future work is optional. For narrative choices and adverse results use the active profile's M02.
