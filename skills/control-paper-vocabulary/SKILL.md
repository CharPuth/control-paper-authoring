# 控制论文高频词汇及其使用场景

按句子的研究动作选择常见词汇，使动词、主语和宾语搭配自然。词库覆盖常用核心表达及场景补充，按功能组织，不是全领域词频排名。

## 使用资料

- 选择或修改用词时，读取 [场景词库](references/vocabulary.md) 中相关条目。共有 51 组（原 48 组及迁移补充的 3 组），包含使用场景、搭配、正例和提示；按动词或条目编号查找。
- 需要正反例或解释修改时，读取 [通用正反例](references/contrastive-examples.md)。E 为语法或搭配问题，T 为术语或修饰关系问题，P 为可选优化。
- 需要结合控制论文原句教学时，读取 [论文原句案例](references/manuscript-examples.md)，按动词、M 编号或 K 编号查找。M 是原句与推荐写法，K 是应保留的表达；案例不依赖原 PDF 才能使用。
- 只有用户询问语料出处或频次时，读取 [语料与来源](references/sources.md)。普通润色无需重新检索文献。

## 选词方法

1. 先识别当前动作：提出方案、定义对象、建模、推导、计算、求解、实现、评价、比较、描述响应或解释结果。
2. 以动作和宾语决定词组，再确定介词与句式。例如 `derive a relation`、`compute an input`、`solve a problem`、`compare A with B`。
3. 从上下文选择主语：作者、控制器、公式、图表或响应都可以作主语。不要把所有句子统一改成 `We propose ...`。
4. 自然的原句直接保留。`use`、`show`、`obtain`、`returns` 和重复术语都是正常表达；不以增加词汇密度或同义词数量为目标。
5. 同一概念保持同一名称。术语、数字和符号作为语言编辑的输入，不延伸为方法实现核查。

关键区分：`propose / present / develop / use` 按当前动作选择；`show / demonstrate / validate / verify` 按宾语和句子任务选择；`reduce an error` 与 `improve accuracy` 使用不同搭配。

公式后解释符号、参数或条件时，必须用小写 `where` 接续同一句，不另起 `Here` 句，并相应调整标点。这是作者确认的文风约定。

## 输出

遵从用户指定格式。普通润色优先给修改后的文字；需要解释时，补充“原句｜推荐写法｜场景与搭配说明”。词汇教学采用“词或词组｜场景｜常用搭配｜正例｜反例或不推荐表达｜原因”。明确区分错误与可选优化，不把 P 类说成期刊禁用。

本 Skill 只处理写作表达，不包含章节写法、数据或内容真实性审查及学术道德条目。不自动加载整篇论文写作流程，也不要求用户解释控制器实现。

由 control-paper-authoring 调用时承担当前配置的 M05，沿用已有任务范围与已读模块，不回调主入口；句式问题交给当前领域 M04。独立使用时可按需结合 control-paper-writing-style，缺少该技能仍可使用本词库。原稿案例依赖自己的上下文，不为新论文预设方法、数据或试验场景。
