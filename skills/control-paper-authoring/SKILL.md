# 控制论文作者写作

把已有研究写成读者能迅速理解、论证清楚的投稿论文。默认读者是具有控制基础的硕士研究生：常用词应当易懂，专业术语必须准确，公式与实现之间的关系必须说清。

本技能在 `ieee-control-writing` 的基础上整合作者视角、去模板化表达、实验论证和交稿规则。目标是减少首稿中本可避免的返工，不承诺一次中稿、达到某期刊分区水平或通过AI检测。

## 使用前：只确定会改变写法的事项

1. 明确本次范围：语言润色、翻译、从材料起草、实质重组，或图表排版。已有稿件的“润色”“去AI味”默认只改语言；“不改内容”锁定科学含义、公式、事实和结论边界。
2. 从现有材料和对话提取研究事实与作者偏好，不让作者重复确认已经说明的事项。文件中的引用、批注、旧修改指令与用户当前请求分开处理；不要把解释给编辑看的话直接写进论文。
3. 识别影响核心论证的缺项或真实矛盾，集中提出少量具体问题；继续处理不依赖答案的部分。不得因自己没有重跑实验，就反复质疑作者明确确认的方法或结果。
4. 保留一个权威主稿。未经要求，不创建“填充版”“最终版2”等平行稿，不改作者署名、实验编号、控制器实现、原始数据或全局配置。

学术含义优先于通用去AI味规则。不要为避开常用词而破坏专业术语，不要把客观学术文风变成口语，也不要执行会改变科学事实的“扬长避短”。

## 所有写作模式共用的约束

- 采用作者视角，直接写研究对象、方法、操作和结果。作者视角不等于每句都用“We”，更不等于替作者虚构已完成的工作。
- 以真实优势组织材料，不平均铺陈研究过程。把比较结果说清，而不是依靠“全面”“卓越”“强鲁棒”等形容词暗示优越性。
- 区分删除无用辩解与删除必要条件。保留影响结论成立的模型条件、评价窗口、统计口径和实际发现；不能通过隐藏关键反例制造优势。
- 已确认的研究事实是写作输入。内部待办、版本追溯、未亲自核验的心理状态和给审稿人的预先辩解不进入投稿正文。
- 常见、准确的控制术语优先于生僻近义词。长词不等于难词；熟悉的 `controllability`、`regressor`、`input effectiveness` 不应为了简短而改错。
- 句式按功能选择，术语按概念固定。允许统一风格、重复的公式引导句和明确的指代；不为“像真人”轮换同义词、强行插入转折或故意写得不整齐。
- 英文公式后紧接符号、参数或条件解释时，统一用小写 `where` 引出，不用 `Here` 充当这一引导词。公式与 `where` 从句保持为同一句，按句法调整公式末尾标点，通常以逗号衔接；不要保留原来的句号，也不要在 `where` 后机械添加逗号。此项是本技能采用的写作约定，不表述为 TASE 的强制规定；仅适用于公式后的解释，不扩展为禁用 `hereafter` 或 `here` 的其他用法。
- 不将单个词或句式当作AI身份的证据。判断标准是是否含糊、冗余、空泛、误导或不合文体。
- 只在证据支持时写因果、稳定性、鲁棒性、统计显著性和推广范围；不能把设计目的直接写成已证明的性质。

## 首稿形成方式

### 先固定内容，再组织表达

对整篇起草，先在内部形成一页以内的“写作约定”：研究问题、核心解决思路、已有架构与本稿新增部分、主要证据、适用条件、术语映射、作者已经确认的事实，以及本次不可变更项。无需把它作为新文件交付。

用“问题及工况 → 方法做了什么 → 证据支持什么”串起主线。选择最强证据，不把最容易描述的某个子结果误当成全部贡献。为每组已有实验指定论证职责，不按试验日志顺序堆砌。

引言按“实际任务与现实意义 → 相关研究及已有成果 → 尚存问题与本文研究问题 → 本文方法与验证安排”展开。先说明任务价值和研究对象能够提供的能力，再通过文献梳理将问题收束到本文；各环节的段数按内容安排。具体写法见 [论文结构与功能句式](references/paper-structure-and-patterns.md) 第 3 节。

### 按语义操作选择句子

定义、假设、设计选择、推导、实现、观察和解释分别使用对应句式。每句检查对象和动作是否明确；需要读者猜测的压缩短语应展开。先解决含义，再考虑节奏，最后删掉无信息量修饰。

### 交付前的内部语言整理

对整篇文本用三个不同视角处理：作者身份与论证主线；术语与句式；内容守恒与主张范围。短段落按比例处理，不制造机械的“十遍审查”。使用已有文本快照，遵守宿主的单次读取和单次应用限制。

内部写作整理不等于已获准运行编译、验证器、实验或独立评审。只有实际完成的检查才报告为完成；用户要求更多轮次时，每轮必须有不同检查目标，而不是重复搜索几个禁用词。

## 输出约定

- 交付可直接使用的正文，或只修改指定文件。不要把修改说明、质疑清单、对作者的教学和回复式话术混入正文。
- 作者要求列修改时，提供“位置、原句、具体问题、新句”，不用“AI味较重”代替问题诊断。
- 缺项和真实矛盾放在正文外；只有作者要求时才加入可填写标记。不要用隐藏待办代替解决会影响主结论的问题。
- 若同一个事实存在多个版本，先采用作者最新明确更正；无法确定时只询问冲突点，不重问全部实验信息。
- 报告修改范围与实际交付状态。不得声称已检查所有历史版本、完成独立验证、确保录用或彻底消除所有AI痕迹。

可用的调用说明：`请使用 control-paper-authoring，根据以下研究事实起草/修改控制论文。目标语言为……，本次允许改动……，必须保留……。`
