# M07 仿真与实验叙事

触发：组织验证章节、选择正文数字、解释比较与消融。按需读取当前领域配置的 M06，核对统计与主张边界；英文表达查当前领域配置的 M04 实验句式。

下述组织方式归纳自 TASE 实例和控制论文改稿经验；[样本及阅读位置](../references/tase-source-notes.md) 只在查来源或扩充语料时读取，不是期刊统一要求。

## 为已有试验分配职责

内部关联“目的、改变因素、对照、可观察证据、支持结论”，不把表格变成必须新增的实验清单。

| 职责 | 重点写什么 |
| --- | --- |
| 标称性能参照 | 基本任务、主要通道响应、必要的稳态与误差指标；客观说明调参 |
| 模块贡献 | 共享基准结构下有无增广的变化；独立调参 PID 的外部比较不能替代该消融 |
| 跨工作点 | 哪些设计设置固定、覆盖范围、配对结果与工况间变化 |
| 指令切换 | 实际改变哪个目标、何时改变、耦合通道与过渡过程；不把分别切换写成同时切换 |
| 饱和等约束机制 | 残差、参数历史、边界驻留或更新活动；任务误差提供必要背景 |
| 现场运行 | 测得环境中的实际行为与任务完成情况；单次无对照运行不单独证明算法优越性 |

不同系列可采用不同参数集。标称结果接近也可建立有效参照，随后转向有区分度的工况；“接近”不自动构成统计等效。不能把良好调参升级为全局最优、相同带宽或穷尽优化。

## 段落与章节

章节开头给任务、对照、共享设置、测量和评价口径；具体试验只补新增条件。必要窗口、初始化、重置和统计定义就近说明，完整配置交给表格。

结果段落建立条件、观察、证据与含义的联系。可从关键现象或决定性数字起笔，不固定句数，不统一以“To verify…”开头或“These results demonstrate…”结尾。只有方法与对照共同支持时才写因果机制。

多项结果需要建立新联系时才写章节小结或独立讨论；没有新信息可进入下一章。整篇结论由当前领域配置的 M01 处理。

## 图、表与正文

- 图展示过程、配对变化、空间行为或分布，表提供精确汇总，正文指出关键变化与研究含义。
- 只选择改变判断的数字，如主要效应量、关键阈值、时间或必要反例；不设数字配额，不逐行翻译表格。
- 瞬态或内部机制可主要解释图中行为，但要写清对象、时段和变化，不能只说“曲线较好”。
- 多通道结果分别解释。阈值必须来自任务要求或材料，不能为淡化差异临时选择；未定义综合指标时不编造“总体 RMSE”。

## 机制解释

投影使两组参数有界时，有界本身不能证明另一补偿项有效。可据数据比较持续增长、边界驻留和累计变化；冻结、总变差变平和收敛是不同结论。

饱和试验若考察无法实现的控制需求引起的无效学习，应优先解释参数与残差。不要把某种执行能力限制推广为“任何控制器都不能改善任何指标”；观察到的性能差异仍保留实际含义。

混合结果围绕最相关的真实收益组织；无关弱项可省略，影响核心结论或关键比较的结果按 M02 先询问作者。结论限定在已有证据覆盖范围，无需反复追加未经测试场景的清单。
