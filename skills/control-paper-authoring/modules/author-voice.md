# M02 作者叙事与结果取舍

适用于所有论文写作。中文动笔前读取 [anti-defensive-writing](../../anti-defensive-writing/SKILL.md)，英文读取 [anti-defensive-writing-en](../../anti-defensive-writing-en/SKILL.md)；混合任务以投稿正文目标语言为主。已在当前上下文完整读取的不重复读。

采用作者视角陈述已完成的方法、实验、结果及意义，围绕真实优势建立最有说服力的主线。不要写成研究日志、自我审查报告或对假想审稿人的答辩。作者已确认的事实可作为写作输入，不因未亲自重跑而反复弱化。

## 配套规则在论文中的适用方式

- “扬长避短”用于选择主线、安排篇幅和表达重点。无关弱项可以省略，不主动罗列缺点，不平均展示所有探索过程，不为局部不占优结果制造泛化的自我否定。
- 对不占优结果，先判断它是否关系核心结论或关键比较。无关内容可删除或移出主线；真实存在的目标差异、条件差异或权衡可用具体事实解释，不编造理由或临时挑阈值。
- 会改变核心结论或关键比较理解的结果，先在正文外询问作者，确认研究定位、证据范围和表述后再处理。可提出缩小主张、调整贡献重点或补充验证的选项；未解决前不发布依赖该问题的结论，其他段落继续修改。
- “不说输”不是禁止陈述必要事实。“性能下降”“仅”等词若承担真实比较或范围定义，不因命中词表直接删除；具体采用什么表述须符合已确认的主张。不得通过删掉关键反例造成误导，不重算数据、不把计划中的工作写成结果。
- 结构组织服从当前领域 M01；不能把配套 skill 的开场建议机械套成固定四句或强制改变已确认的引言顺序。

删除服务于改稿回复的语句，如“按作者要求”“为避免审稿人误解”。直接交代真实设置。内部版本追溯、待核事项和写作过程留在正文外；方法所必需的条件和复现信息仍用正式表述给出。

该模块适配第三方指令，不修改其独立用途。措辞、标点、词汇和结果组织分别由当前领域 M03、M05、M07 处理。
