# M06 技术含义与证据

触发：涉及模型、控制设计、实现、统计、比较或结论的起草和实质修订；语言修改发现技术歧义时按需查阅。研究事实冲突的处理遵循 [主入口](../SKILL.md) 的任务边界。

## 事实记录

从材料与作者已确认答案中保留：对象与任务、架构与接口、变量及坐标、假设与单位、采样顺序、初始化和重置、实验编号与调参范围、重复次数、评价窗口和主张范围。内部区分作者确认、材料显示、推断和待澄清；这些溯源标签不逐句写入投稿正文。没有实际冲突时，不因未亲自重跑实验而重新询问。

## 模型与信号

| 需要区分 | 写作判断 |
| --- | --- |
| 控制器输出、分配器输入、执行器设定、预测输出、实际力、传感器测量 | 按真实接口命名；没有力测量就不能补出目标力与实测力做差的闭环 |
| 完整模型与局部模型 | 说明用途、简化条件及输入；等价性需对照状态、运动学、惯量、耦合与坐标，不能凭“六自由度”认定 |
| 自由度与状态数 | 六个运动自由度不等于只有六个标量状态方程 |
| 坐标分量与物理方向 | 保留变换方向、轴正方向和旋转顺序；混合坐标的输入向量不能整体误标为单一坐标系 |
| 测量值、基准与相对变化 | 如原定义为 h、h0，则相对变化为 h-h0；不改写原变量或猜测传感器参考点、浸没深度 |
| 输入系数与加性扰动 | input effectiveness 与 additive disturbance 不可互换 |
| 参考模型误差与指令误差 | 名称分别对应实际公式，不合并两种跟踪目标 |
| 近似、定义、设计与推导 | 保留 approximated、defined、selected、obtained 等词的数学作用 |

没有技术检查任务时不擅自重推全文；发现明确符号或维度矛盾时指出具体位置，不用泛泛的“理论一致性待确认”替代问题。

## 实现时序

- 区分当前与上一周期信号、更新方向与包含积分/投影的完整更新律、固定设计参数与在线估计量。投影下界防止除零本身不证明稳定或收敛。
- 原样保留算法的积分、限幅、投影、计算和存储顺序，以及未激活分量。不加入未实现的姿态补偿、饱和处理、预测器或滤波器。
- 独立试验开始、同次指令切换、参考模型初始化和参数估计初始化分别陈述；不默认每次切换都重置。
- 分别保留仿真与实物的参数集，以及各系列内部“不重新整定”的范围。不能把系列内固定扩大为所有验证共用参数。
- 采样间隔、求导窗口、滤波、缺口处理与插值均来自实际实现，不为写得完整而补造。

## 评价与统计

- 区分单次代表轨迹、平均轨迹、独立重复试验和池化样本。重复次数、独立性、随机次序及代表试验选择规则需要真实依据。
- 保留评价窗的起止事件、相对时间零点、端点约定，以及窗口属于各试验还是配对组共同窗口。代表试验停止线不能代替所有重复的截止时间；较早停车时间不能改成较晚或平均时间。
- 保留 RMSE 的采样/时间加权方法。各次试验 RMSE 的均值不同于平均轨迹的 RMSE；最大工况级 RMSE 不同于最大瞬时误差。
- 试验间标准差、时序标准差、标准误、置信区间、极值范围和箱线图须有各自定义；不默认箱线图采用某个须长规则。
- 统计对象必须匹配，不能将“代表试验指标 ± 重复试验标准差”写成“均值 ± 标准差”。无未舍入值时不得假装掌握原始精度。

## 主张需要什么证据

| 主张 | 必要依据与范围 |
| --- | --- |
| 跟踪改善、跨工况收益 | 明确通道、指标、比较对象及覆盖工况；一个通道不能代替另一个 |
| 整体误差更低 | 已定义并实际计算的综合指标；否则分别报告各通道 |
| 设计参数无需重新整定 | 哪些设置在什么试验范围内固定 |
| 某模块产生收益 | 对应对照或机制分析；同时开关多个部件只能支持组合作用 |
| 统计显著、等效或可比 | 相应检验或明确判据；均值和标准差、视觉接近不足以单独支持推断 |
| 稳定性、收敛、全局鲁棒性 | 相应理论结果与条件；有限工况轨迹不能直接推广，有界、渐近收敛、指数收敛和实用稳定不是同一性质 |

保留主张成立所需的 local、nominal、measured、estimated、previous、mean、per-condition 等限定。主张与已知数据冲突时不能通过隐藏数据维持结论；涉及核心结论或关键比较的不利结果，先按当前领域 M02 询问作者，再确定定位、主张与呈现方式。
