# 改稿经验及其适用范围

本技能提炼自本次ROBIO稿件任务中可见的作者要求、修改案例，以及已有 `ieee-control-writing` 的句式与来源说明。它不是对所有历史文件逐版执行差异分析的报告，也不是对IEEE论文写法的频率统计。

## 可迁移的决策，而非原样复制的偏好

| 可见改稿问题 | 可迁移规则 | 不要错误泛化为 |
| --- | --- | --- |
| 论文主线被收窄成速度切换时的深度保持 | 核心问题要覆盖作者实际研究目标，局部结果承担证据职责 | 所有论文必须同时研究速度与深度 |
| 多次写理论实现是否一致尚待确认 | 接受作者明确确认的事实，内部待办不入正文 | 已知矛盾也不得指出 |
| 为对比控制器的调参写辩解 | 描述真实设置和调参任务，不反复解释动机 | 可隐瞒比较条件或不公平设置 |
| 写“最优”“充分优化”“相同带宽” | 只写实际做到并有依据的调参条件 | 任何研究都不能讨论最优性 |
| E2被描述为两个通道全面领先 | 对通道、指标、条件分别作主张，突出真正主要收益 | 不占优势的指标应从表中删除 |
| 摘要和引言加入未实施的姿态补偿 | 方法动作必须与算法和接口一致 | 水动力研究不能讨论姿态作用 |
| 使用含糊的force-level或force command | 定义控制变量、坐标系和分配接口 | 这些词在所有控制论文中都错误 |
| 把上一输出写成预测实际力 | 精确保留采样索引和信号含义 | 所有算法都必须采用上一周期输出 |
| h与h-h0的定义反复变化 | 以作者最新确认锁定测量值、基准和相对变化 | 任何平台的h都采用同一测量定义 |
| 将实物试验简称为hardware | 在易歧义处写具体实验场景 | 全文删除hardware，包括真正硬件含义 |
| speed与velocity、loads与forces混用 | 按物理量和数学对象统一术语 | 全局字符串替换，不考虑向量与力矩 |
| maximum errors不等于表中Max. | 说明统计量，例如最大工况级RMSE | 所有最大误差都应称RMSE |
| 指令切换被写成同时改变两个目标 | 保留每次实际改变的变量 | 所有切换试验都只允许单变量变化 |
| 静止基准、求导窗口和重置规则多次澄清 | 记录已确认答案，区分独立试验与同次切换 | 把该稿件的窗口长度与初值带到新研究 |
| 代表试验时间被用作五次试验共同时间 | 分开代表曲线与重复统计，准确说明窗口 | 必须一律用最早停车时间 |
| 未提供的长采样缺口被加入统计说明 | 不为“严谨”创造不存在的数据问题 | 忽略真实缺失数据或异常 |
| 句子they form使定义不清 | 公式前给出明确对象，代词需有清楚指代 | they form是非学术或禁用短语 |
| 喜欢高级单词、自造复合短语 | 用常见词表达完整关系，保留专业术语 | 所有长词和复合术语都不允许 |
| 通篇机械轮换句式或同义词 | 风格可统一，句式由信息功能决定 | 每个句子都必须不同，或都必须相同 |
| 中文为简洁强凑短词语 | 展开动作与对象，减少无信息定语 | 所有中文学术表达都应口语化 |
| 参考文献数量、年份和格式存在问题 | 按相关性核实出版信息，遵守目标格式 | 所有论文至少18篇，或IEEE禁止DOI |
| 图1只有图注，没有正文引用 | 每幅必要插图都有准确的正文引用 | 每幅图只能在引言中引用 |
| 图例、箭头、停车文字妨碍阅读 | 改善布局与符号说明，保留数据和信号意义 | 所有图都必须删除停车文字 |
| 最优值加粗 | 按预先定义的方向逐工况逐指标比较 | 只加粗提出方法，或把标准差也当成性能排名 |
| 三位小数被遗漏到标准差之外 | 数值格式覆盖均值与标准差，格式不替代原统计值 | 所有参数都显示三位小数，允许小量变成0 |
| 反复说已自检却仍遗漏内容 | 检查要有不同目标与可见证据，报告真实范围 | 机械声称检查十遍即可保证质量 |

## 句式来源的边界

既有技能的初始样本是两篇IEEE Transactions on Automatic Control论文；来源和阅读范围见 `../../ieee-control-writing/references/source-basis.md`。本技能沿用其按定义、设计、推导、实现和结果区分句式的方法，并加入本轮修改经验。

“IEEE控制论文常用写法”在这里是编辑定位，不代表已完成大样本语料分析。不得把旧的、特定年份和特定评价体系的Q1信息写成当前所有意义上的“一区”；本技能也不继承一项保证稿件学术水平的承诺。

例句、中文修改建议和规则表是编辑归纳，不是参考论文的逐字引文。模仿的是语义功能和清楚的表达方式，不是复制句子、结论、假设、数据或引用。

## 扩展此技能时

优先加入会改变写作决策的真实案例，而不是越来越长的禁词表。每项新规则都应附上适用条件，检查它是否只是某个平台的局部偏好。

需要扩大句式样本时，使用相关领域的出版方、作者或机构全文，记录实际阅读的章节，并区分观察到的表述与自行归纳的框架。不要把未公开的稿件、数据或完整对话发送给外部服务以获取“风格评价”。

新的试写和独立评估须获得相应授权，并与原稿隔离。尚未完成独立试写时，只能说已整理并创建技能，不能说已证明它能够让任何论文一次达到预期。
