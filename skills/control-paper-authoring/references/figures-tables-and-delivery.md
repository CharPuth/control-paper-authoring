# 图表、文献与交稿

本文件用于用户要求图表、模板、参考文献或文件交付时。单纯润色段落不触发整稿重排、下载文献、运行实验或编译。

## 1. 图表是证据，不是装饰

每个图表应有对应正文引用，并在相应结果讨论附近出现。只有标签和图注不算正文引用。检查编号、引用对象与实际内容是否一致，不因挪动源代码顺序而错误更换实验编号。

保留曲线、单位、数据范围和评价口径。可以调整布局、裁剪无关空白、移动标注或去掉冗余文字，但不能生成不存在的实物场景、改变曲线形状或遮挡不利数据。

框图必须保留对读者理解算法必需的信号路径，特别是实际的反馈量、姿态接口、延迟或上一周期输出。视觉简化不能把估计信号画成测量信号。

统一控制器名称、颜色、线型和排序。简称与编号都可以使用，选择适合当前论文的清楚方案并保持一致，不能宣称IEEE只允许其中一种。

## 2. 代表曲线与重复统计分开说

若图展示代表试验，图注中明示；表格统计多次独立试验时，说明统计单位和次数。图中的代表性停车线不是每次试验共有的结束时间。

竖线等图形符号的意义在图例或图注中解释即可，是否再加文字标记由可读性和作者要求决定。图注不重复整段结果讨论，但必须保留区分指令、控制器、停止或评价区间所需的信息。

## 3. 数值格式不改变计算依据

区分“小数点后n位”与“n位有效数字”。按作者要求执行舍入，并统一处理均值和标准差，不能只改加减号前面的值。

三位小数的示例：

| 原显示值 | 三位小数显示 |
| --- | --- |
| 0.0185 | 0.019 |
| 0.00845 | 0.008 |
| 0.0620 | 0.062 |
| 0.0415 | 0.042 |
| 0.249 ± 0.0415 | 0.249 ± 0.042 |

遵守作者或期刊指定的舍入规则；未另行指定时，常规十进制四舍五入。程序格式化应正确处理十进制半舍入，避免二进制浮点表示造成意外结果。LaTeX中的 `\pm`、粗体命令和科学计数法不能使数值漏掉。

显示精度不等于测量精度。百分比、排序和统计计算优先使用可用的未舍入数值，不从已经格式化的表格重新推算。没有未舍入统计值时，不假装拥有；可按现有数字做注明近似的比较，或保留绝对数值。

结果表的统一格式不自动扩展到整数计数、实验编号、物理参数和极小学习率。避免把非零参数舍入成0；范围不明确且会影响含义时，先说明采用的范围或询问。

## 4. 最优结果加粗

先确定指标方向和分组：RMSE通常越小越好，成功率通常越大越好；每个工况、通道和统计量分别比较。不要只给提出的方法加粗。

对于“均值 ± 标准差”，默认按均值判断，并只加粗最优均值；标准差本身不是该性能指标的另一场排名。作者明确要求整组加粗时再统一处理。

有未舍入值时据此判断。舍入后出现相同显示值，但原值不同，可保留原值排名并用简短表注说明；没有更精确依据时，不人为区分并列值。不要悄悄增加小数位来制造可见优势。

## 5. 排版约束的优先顺序

使用对应会议或期刊的正常模板、字号和间距。篇幅不足时优先删除重复叙述、改善图表布局、调整浮动体位置和尺寸；不要以异常缩小正文、图注或坐标字体满足页数。

正文修改可能改变分页。作者指定某表在第五页或参考文献在第六页，只对当前稿件有效，不是通用会议规范。六页、18篇文献、三位小数、停车线无文字也都不是本技能的全局要求。

表注对齐、参考文献DOI显示、匿名规则和页数限制应遵守当前实际模板、官方要求及作者明确选择。不得将某次修改偏好说成IEEE统一规定。

编译和视觉检查须遵守用户及宿主的授权。获准检查时，区分以下事项：编译成功、引用解析、页数、缺字、裁切与重叠、图表位置和可读性。编译成功不能替代逐页查看；没有做过的检查不能写成已完成。

## 6. 文献筛选与作者已有工作

优先选择与平台、任务、方法或比较有关的可信来源。较新不自动更好，较早也不自动价值低；必要的基础理论、经典方法和原始提出文献可保留。

引用作者团队已有成果时，核实作者、题名、出版状态、正式年份、卷期和页码，区分在线发表年份与卷期年份。说明相关技术关系，不把作者重合当作相关性的充分证据。

已发表的平台、结构、感知、姿态控制成果可以支持背景，不能成为本文首次提出的贡献。不要仅为了文献数量添加同一成果的多个版本或无关自引。

新文献应有正文引用，删除文献应同步处理引用键；按目标格式统一作者写法、期刊缩写、页码或文章号。作者要求去除DOI时只改显示格式，不篡改出版信息。

用于学习句式的论文不必进入科学参考文献列表。若用户要求核实最新政策、期刊分区或扩展文献，应检索相应来源；日常语言修改不需要重新搜索已具备的文献材料。

## 7. 匿名与题名完整性

在匿名要求适用时，以通用平台名称和中性第三人称介绍已发表工作，避免“我们的前作”与作者身份之间的直接连接。根据当前会议规则处理署名、致谢、链接、文件元数据等项目。

不通过改写已发表论文的原始题名伪造参考文献。正文不出现平台专名，并不自动消除照片、独特机构或引用关系带来的识别可能；是否进一步处理取决于实际规则和作者授权。

## 8. 只报告实际交付状态

提供指定主稿与实际生成的产物。简述修改范围，不自动创建额外报告、镜像主稿或版本分支。需要修改清单时列出真实改动；格式化属于显示修改，不应声称重新计算了实验数据。
