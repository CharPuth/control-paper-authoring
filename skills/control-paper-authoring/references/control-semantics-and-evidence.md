# 控制语义与证据约束

用于防止“语言更漂亮，但方法已经被改错”。语言编辑不等于技术重设计，也不等于重新执行实验。

## 1. 用现有材料建立轻量事实记录

记录真正影响表述的项目，不为了表格完整而反复索取无关信息。

| 类别 | 需要锁定的内容 |
| --- | --- |
| 对象与任务 | 平台通用名称，控制变量，运动模式，目标工况 |
| 架构 | 新增控制模块，保留模块，输入输出接口，实际反馈量 |
| 数学 | 状态、误差、参数、坐标系、单位、近似和适用条件 |
| 实现 | 采样时序，测量和估计来源，输出存储，初值与重置规则 |
| 试验 | 编号，比较方法，调参范围，独立重复次数，评价窗口 |
| 证据 | 代表轨迹还是重复试验统计，均值/标准差/最大值的定义 |
| 交稿 | 当前主稿，版式约束，允许改动的范围，已确认的作者偏好 |

在内部区分作者明确确认、材料直接显示、写作者推断和待澄清。不要把这些溯源标签逐句贴进投稿正文。作者确认足以作为写作依据，除非与现有材料有实际冲突。

## 2. 信号语义不能靠近义词替换

控制器输出、分配器输入、执行器设定、预测输出、实际作用力和传感器测量不是可互换的名字。

如果没有力传感器，就不能仅因使用了 `force command` 一词而补出“目标力与实测力做差”的闭环。若实际架构在虚拟输入上建模，可以使用 `virtual control input` 并定义变量及其进入分配器的关系。

`force command` 在其他论文中可能是准确术语；本技能不全局禁用。选择词语的依据是实际接口，不是沿用某一平台的措辞偏好。

明确以下区别：

- `F[k-1]` 与 `F[k]`：上一周期输出与当前输出。
- 参数更新方向与完整的离散更新：是否已经包括限幅、积分和投影。
- 控制器的设计参数与在线自适应估计量：固定前者不等于冻结后者。
- 参考模型跟踪误差与目标指令跟踪误差：二者不能共用名称却采用不同公式。
- 设计补偿项与已验证的补偿对象：不能顺手加入姿态补偿、饱和处理或未实施的执行器估计。

## 3. 从完整模型到局部模型

说明完整模型用于什么，控制设计抽取了哪些变量，以及简化需要哪些条件。只有在确有依据时，才说明其等价关系。

六自由度通常描述六个运动自由度，采用位置/姿态与相应速度作为状态时可以有十二个标量状态方程。紧凑模型是否对应某组展开方程，要对照状态定义、运动学映射、质量惯量、耦合项及输入坐标，而不是仅凭“六自由度”名称认定一致。

没有检查任务时，不擅自重推全文；发现明确的符号或维度矛盾时，在正文外指出具体冲突，再按授权修订。不得用模糊的“理论一致性有待确认”污染全文，也不得忽略已知矛盾。

## 4. 坐标、测量参考和符号

对旋转或投影前后的力、速度或误差，分别说明所属坐标系。不能把某坐标分量称为另一物理方向上的实际作用力。

对深度、距离或位移，区分测量值、基准值与相对变化。例如：若作者定义传感器读数为h、静止基准为h0，则相对变化是h-h0，不应重新定义h为相对值。还需保留正方向和目标偏置的关系。

传感器位置、标记点或机体参考点没有材料依据时，不在图中自行标注。不能把测得的垂向坐标直接称为某水翼的浸没深度。

标量速度大小使用 `speed`；向量速度使用 `velocity`。深度指令数值的增加或减小与物理上浮、下潜的对应关系由坐标约定决定，不能凭日常语言推断。

## 5. 初始条件与重置

独立试验开始、同一次试验中的指令切换、参考模型初始化和参数估计初始化是不同事件。分别保存已确认规则，不默认每次切换都重置所有状态。

若仿真与实物试验分别调参，应明确这一点。若每个试验系列内部设计参数保持不变，应将“不重新整定”的范围限定在该系列，不扩大为仿真和实物共用全部参数。

采样间隔、求导窗口、滤波方法和缺口处理都需要真实依据。不得因为统计公式看起来更完备就自行添加“长采样缺口”或插值处理。

## 6. 评价窗口与统计对象

评价窗口是方法定义的一部分，不是图注中的可删杂项。

- 共同窗口、每个控制器自己的窗口和每次试验自己的窗口不能混用。
- 代表试验的结束时间不能代替重复试验总体的统一结束时间。
- 从指令切换开始时，应说明相对时间零点和结束事件。
- 作者指定“较早停车时间”时，不能改成平均时间、较晚时间或图上读出的单个时间。
- 均值和标准差的统计对象要明确，例如每次试验RMSE，而不是所有时刻的误差样本。
- `maximum per-condition RMSE` 不是最大瞬时误差；箱线图的须也不能自动解释为1.5倍四分位距。

若窗口已经由作者澄清，沿用最新口径。只有新材料产生实质冲突时再询问，不把没有原始记录误当成作者尚未回答。

## 7. 对结论分配证据职责

| 主张 | 最低需要的实际依据 |
| --- | --- |
| 目标跟踪得到改善 | 指定通道、指标、比较对象与评价条件 |
| 设计参数无需随工况重新整定 | 明确哪些设置在什么试验范围内固定 |
| 跨工况表现较好 | 多个工作点下相同评价口径的结果，主张限于已覆盖范围 |
| 两个通道均优于对照 | 两个通道的数据分别支持，不能由一个通道代推另一个 |
| 整体跟踪误差更低 | 已定义且实际计算的综合指标；否则分别报告通道结果 |
| 统计显著改善 | 合适的检验及统计报告；形容词不能代替检验 |
| 稳定性或收敛保证 | 相应数学结果、条件与证明依据，不仅是轨迹图 |
| 性能来自某个组件 | 实际机制分析或对应消融，不能凭架构图断言 |

核心优势不是让所有指标都赢，而是说明已成立的改进为什么与任务有关。相关的不占优结果可保留在表格中并适度讨论；若它直接推翻主张，就应修正主张，不得通过去AI味规则掩盖。

## 8. 限定词的含义检查

修改 `local`、`nominal`、`measured`、`estimated`、`previous`、`mean`、`per-condition`、`independent` 等词时，先确认删改后是否改变对象或适用范围。

保留有含义的精确限定，删除的是重复的免责套话。可以直接说“在所测试工况下”，不必再加“这并不意味着我们声称已经解决所有可能问题”。
